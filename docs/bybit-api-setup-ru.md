## Прежде чем начать

1. **Двухфакторная защита на Bybit должна быть включена** (Google
   Authenticator + SMS). На финальном шаге Bybit попросит коды — без
   них создать ключ не получится.
2. **Откройте текстовый файл** (или менеджер паролей: Bitwarden,
   1Password, заметки на телефоне). **API Secret покажут один раз**
   и он исчезнет навсегда — если не сохранили, придётся создавать ключ
   заново.

## Шаг 1. Открыть страницу создания ключа

В Bybit идите в **Profile → API**, или сразу:
<https://www.bybit.com/app/user/api-management>

Нажмите **«Create New Key»** → выберите **«System-generated API Keys»**.

## Шаг 2. Базовые поля

- **API Key Usage:** `API Transaction` (по умолчанию, ничего не менять)
- **Name for the API key:** любое имя, например `Robot Claude`

## Шаг 3. Permissions — критически важно

### Тип доступа

- **Read-Write** (так система сможет открывать сделки)
- **No IP restriction** (без привязки к IP — так проще)

> ℹ️ Bybit предупредит что без IP-привязки ключ **истечёт через 3 месяца**.
> Это нормально — через 3 месяца просто создадите новый ключ по этой
> же инструкции и вставите в кабинете.

### Галочки в таблице прав

**✅ Поставьте галочки ТОЛЬКО ТУТ:**

| Раздел | Подраздел | Право |
|---|---|---|
| **Unified Trading** | **Contracts** | ✅ Orders |
| **Unified Trading** | **Contracts** | ✅ Positions |

Это всё. Два пункта в разделе «Contracts». Они означают «открывать,
закрывать и читать состояние позиций на USDT-фьючерсах» — это
ровно то что нужно нашей системе и больше ничего.

**❌ НЕ ставьте галочки тут:**

- `SPOT → Trade` — не нужно, мы не торгуем спотом
- `Assets → Account Transfer` — переводы между аккаунтами
- `Assets → Subaccount Transfer` — переводы на субаккаунты
- `Assets → Withdrawal` — **вывод средств** (этого права у нас быть НЕ должно)
- `Assets → Exchange / Convert` — конвертация активов
- `P2P`, `Bybit Pay`, `Crypto-Fiat Conversion`, `Community posts` — посторонние

Если случайно поставили — снимите. Особенно **Withdrawal**: отсутствие
этого права = гарантия что мы не сможем вывести ваши деньги, даже если
бы захотели.

## Шаг 4. Submit + двухфакторка

Нажмите **«Submit»**. Bybit покажет окно «Security Verification»:

1. **SMS-код** (придёт на ваш телефон автоматически)
2. **Google Authenticator** — 6 цифр из приложения

Введите оба, нажмите **«Next Step»**.

## Шаг 5. 🛑 СТОП! Сохраните ключи ПЕРЕД «Understood»

После успеха появится окно **«Key successfully added»** с двумя полями:

- **API Key** — длинная строка букв/цифр (например `oubxfckaszob9ySaBu...`)
- **API Secret** — ещё длиннее, **показывается ОДИН РАЗ** и больше никогда

**Не нажимайте «Understood» сразу.** Сначала:

1. Скопируйте **API Key** → вставьте в свой текстовый файл / менеджер паролей
2. Скопируйте **API Secret** → туда же
3. **Сохраните файл**

И только теперь нажимайте **«Understood»**.

> ⚠️ Если нажать «Understood» не сохранив Secret — он пропадёт
> навсегда. Bybit не даёт его посмотреть повторно. Придётся удалять
> ключ и создавать новый с нуля.

## Шаг 6. Вставить в наш кабинет

Откройте <https://robotclaude.biz/account/api-key>, вставьте API Key
и API Secret из вашего сохранённого файла, нажмите **«Проверить и
сохранить»**.

Если всё ок — увидите ваш баланс на счёте. Можно идти выбирать стратегии.

## Часто задаваемые вопросы

### Что мы реально можем делать с вашим ключом?

Только три вещи:
1. Открывать market-позиции на USDT-фьючерсах (Buy / Sell)
2. Закрывать существующие позиции (reduce-only)
3. Ставить защитный SL на позицию

Всё. Доступа к споту, выводам, переводам, профилю, KYC-данным — **нет**.

### Можно ли отозвать ключ?

Да, в любой момент:

- **В нашем кабинете** — кнопка «Отключить ключ» на странице `/account/api-key`.
  Открытые позиции продолжат жить до естественного выхода.
- **На Bybit** — на странице API management удалите ключ. Сразу после
  этого Bybit будет отклонять любые наши обращения.

### Что с комиссиями Bybit?

Стандартные комиссии биржи (taker 0.055% × 2 стороны = 0.11% за круг).
Это плата бирже, нам ничего не идёт. Все наши публичные цифры на
страницах стратегий уже учитывают эту комиссию — реальные результаты
у вас будут такие же.

### Что если у меня кончится баланс?

Bybit отклонит ордер с ошибкой insufficient_balance. Мы фиксируем это
в логах и продолжаем работу — для следующих сделок ключ остаётся
рабочим. Просто пополните баланс когда сможете.

### Ключ истечёт через 3 месяца — что делать?

За пару дней до истечения Bybit пришлёт уведомление на email.
Создавайте новый ключ по этой же инструкции, отключите старый в нашем
кабинете и подключите новый. Открытые позиции при этом не пострадают.
